# HEMOPI — Fluxo atualizado

## Trecho chegada → pré-triagem (v2)

### Novos losangos decisórios
1. **Como chegou? Agendado?** → SIM (check-in QR) / NÃO (espontâneo)
2. **Prioridade legal? (Lei 10.048)** → senha prioritária / normal
3. **Idade na faixa de doação?** → especial (16–17, 60–69) / segue
4. **Qual a rota?** → doador / 2ª amostra / paciente
5. **Apto na pré-triagem?** → SIM (triagem clínica) / NÃO (inapto por peso, PA, Hb)
6. **Pode doar hoje?** (triagem clínica)

### Base normativa
- RDC 34/2014: peso ≥50 kg; Hb mulheres ≥12,5 / homens ≥13,0
- Lei 10.048: prioridades
- Site Alexandre WF-M03-003, 011, 013, 014
